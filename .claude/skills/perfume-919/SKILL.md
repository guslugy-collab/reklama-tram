# 9.19 PERFUME — гайд по сайту-каталогу

Каталог парфюмерии с тёмной luxury-эстетикой. Прямые поставки из Турции и ОАЭ,
оригиналы и масляная парфюмерия, опт и розница. Заказ оформляется через Telegram
(корзина → одно сообщение). Владелец — магазин из Махачкалы, Telegram
`@PERFUME_9_19`.

## Стек (по умолчанию)

**Статический сайт: HTML + Tailwind (CDN) + ванильный JS, деплой на GitHub Pages.**
Товары хранятся в `products.json`, фильтры/поиск/корзина считаются на клиенте.
Это сознательный выбор: каталог правится вручную, чекаута и аккаунтов нет, а
владелец уже ведёт статический сайт на GitHub Pages — так проще и бесплатно.

Если пользователь явно попросит **Next.js 14 + Supabase + Vercel** — переключайся
на него: та же дизайн-система и та же схема данных, но товары читаются из таблицы
Supabase `products`, а корзина — в React-состоянии/localStorage. Не тащи Supabase
без явной просьбы.

## Дизайн-система (обязательна к соблюдению)

```css
:root{
  --bg:      #0f0d0b;   /* основной фон */
  --gold:    #b8935a;   /* золотой акцент */
  --text:    #f0ebe3;   /* основной текст */
  --border:  rgba(184,147,90,.25); /* границы 0.5px с золотым оттенком */
  --muted:   rgba(240,235,227,.6);
}
```

- **Шрифты:** `Cormorant Garamond` (serif) — заголовки, крупная типографика;
  `Jost` (sans) — тело, кнопки, подписи. Подключать через Google Fonts.
- **Границы:** тонкие, `0.5px` (на ретине) / `1px` с `--border`, много воздуха.
- **Эстетика:** минимализм, тёмный фон, золото дозированно (акценты, hover,
  тонкие линии), крупные заголовки serif с широким `letter-spacing`, спокойные
  анимации (fade/translate 300–500ms). Никаких ярких цветов и тяжёлых теней.
- **Кнопки:** прозрачные с золотой рамкой; при hover — заливка золотом, текст
  становится тёмным (`--bg`).

## Структура страниц

1. **Главная (`index.html`)** — hero: крупное «9.19 PERFUME», подзаголовок
   «Оригинальная парфюмерия и масляная. Прямые поставки из Турции и ОАЭ», строка
   статистики (200+ ароматов · опт от 5000₽/30гр), CTA «Смотреть каталог» +
   «Написать в Telegram». Ниже: хиты продаж, блок доверия (доставка/оплата),
   отзывы, подписка со скидкой — по мере наполнения.
2. **Каталог (`catalog.html`)** — сетка карточек 3 колонки (планшет 2, моб. 1),
   фильтры: Все / Оригиналы / Масляные / Мужские / Женские / Унисекс; поиск в
   реальном времени по названию и бренду; опционально фильтр по бренду и
   сортировка (цена ↑↓, новинки).
3. **Карточка товара** — модалка или отдельная страница: название, бренд, тип
   (оригинал/масло), объём(ы), цена (розница/опт), ноты, описание, статус
   наличия, бейдж (Хит/Новинка), кнопка «В корзину» / «Заказать в Telegram».
4. **О нас (`about.html`)** — текст о магазине, фото, контакты, преимущества.
5. **Контакты (`contacts.html`)** — Telegram `@PERFUME_9_19`, город Махачкала,
   (опц. WhatsApp), время работы, карта.

**Навигация:** логотип «9.19 PERFUME» слева; ссылки Оригиналы / Масляные / Опт /
О нас; кнопка Telegram справа. На мобильном — бургер-меню. Подвал: документы
(политика конфиденциальности, согласия), реквизиты, соцсети.

## Схема данных (`products.json` или таблица Supabase `products`)

```json
{
  "id": "uuid|number",
  "name": "string",              // название аромата
  "brand": "string",             // бренд
  "type": "original | oil",      // оригинал / масляный
  "gender": "male | female | unisex",
  "volume": "string",            // «30 гр», «50 мл» (или массив фасовок)
  "price": 0,                     // розница
  "price_wholesale": 0,           // опт (за фасовку)
  "is_wholesale": false,          // доступен оптом
  "notes": "string",             // ноты: верх / сердце / база
  "description": "string",       // краткое описание
  "badge": "hit | new | null",   // бейдж на карточке
  "in_stock": true,              // наличие
  "image_url": "string",         // фото (placeholder, если пусто)
  "created_at": "ISO date"       // для сортировки «новинки»
}
```

Если фасовок несколько (как у floralodor: цена за мл/гр, мин. фасовка) —
храни массив `variants: [{ volume, price, price_wholesale }]` и показывай
«от N₽» + цену за единицу.

## Заказ через Telegram (корзина на несколько товаров)

- Кнопка «В корзину» на карточке добавляет позицию в корзину (в памяти +
  `localStorage`).
- Иконка корзины в шапке со счётчиком; в корзине — обязательная галочка согласия
  на обработку данных (как уже сделано в проекте кафе) перед оформлением.
- «Оформить заказ» открывает
  `https://t.me/PERFUME_9_19?text=<предзаполненное сообщение>` — со списком
  товаров, объёмов, цен и итогом. Текст обязательно `encodeURIComponent`.
- Одиночный «Заказать» на карточке — тот же механизм, но с одним товаром.

Пример сообщения:
```
Здравствуйте! Хочу заказать:
1. Amouage Interlude — оригинал, 50 мл — 8500₽
2. Ard Al Zaafaran (масло) — 30 гр — 4500₽
Итого: 13000₽
```

## SEO и техобвязка

- `<title>` и `meta description` на каждой странице; Open Graph (`og:title`,
  `og:description`, `og:image`), Twitter card.
- `robots.txt`, `sitemap.xml`, favicon, `JSON-LD` (Organization + Product).
- Placeholder-изображение для товаров без фото.
- Адаптив: 3 → 2 → 1 колонка; тап-таргеты ≥ 44px; `tel:`/`mailto:` при наличии.
- Аналитика (Яндекс.Метрика) при запросе.

## iOS-совместимость

Сайт часто открывают с iPhone. Применяй практики: `playsinline` и явный `play()`
для фоновых видео, `tel:`/ссылки, работающие с одного тапа, отсутствие
залипающих `:hover` на тач-устройствах. При жалобах на Safari/iPhone — используй
скил `ios-compatibility`.

## Чек-лист при сборке/доработке

1. Соблюдены токены дизайн-системы (цвета, шрифты, тонкие золотые границы).
2. Каталог: фильтры + поиск работают в реальном времени, моб. = 1 колонка.
3. Карточка содержит все поля схемы; бейдж и «нет в наличии» отображаются.
4. Корзина → Telegram-ссылка с корректным `encodeURIComponent` сообщением.
5. SEO-теги и og на месте; адаптив проверен на мобильном.
6. Новые товары добавлены в `products.json` (или Supabase) без правки логики.
